How I work

AI helps me build. I own the result.

Research, specification, implementation, checks, release and maintenance stay connected. I direct Claude Code, Codex and MCP-connected tools, and I verify and release what they produce.

  1. Source Start from the real record: the customer’s day, the rules, the existing data.
  2. Spec Write down what done means before anything is built.
  3. Bounded task Hand the agent a task small enough to inspect.
  4. Change Read what actually changed, not what was described.
  5. Check Run the tests, then try it by hand.
  6. Release Ship it, then keep it running.

The bench illustrates the method. It is not an artifact from a particular product.

Live league platform · custom rules

Playing for Keeps

I built a fantasy-hockey platform around one league’s custom contracts, roster rules, salary cap, fees and communication.

The problem
Ordinary fantasy products cannot express one league’s contract, roster, salary-cap and fee rules as a single system.
My part
Domain decisions, architecture, AI-assisted implementation, tests, release and ongoing league operation.
What I built
Custom roster and contract logic, cap accounting, fee tracking, authentication and chat.
Where it stands
Live league platform. Member names, finances and chat stay private, so there is no public demo yet.
